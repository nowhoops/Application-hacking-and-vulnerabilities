## The working one

The working solution 
```c
void decode(char *s) {
    for (int i = 0; s[i] != '\0'; i++) {
        s[i] = ~s[i];
    }
}

int main() {
    char input[20];

    /* Obfuscated password (no plain text in binary) */
    char obf_password[] = {
        ~'s', ~'a', ~'l', ~'a', ~'-',
        ~'h', ~'a', ~'k', ~'k', ~'e',
        ~'r', ~'i', ~'-', ~'3', ~'2', ~'1',
        '\0'
    };

    printf("What's the password?\n");
    scanf("%19s", input);

    /* De-obfuscate at runtime */
    decode(obf_password);

    if (strcmp(input, obf_password) == 0) {
        printf("Yes! That's the password. FLAG{Tero-d75ee66af0a68663f15539ec0f46e3b1}\n");
    } else {
        printf("Sorry, no bonus.\n");
    }

    return 0;
}
```

## Explanation (written for myself)

This is a `for` loop with `int`, which is a datatype that stores numbers.

- `i` starts at `0`
- `s[i] != '\0'` means: keep looping until we hit the **null terminator**

So it’s kind of like in Python:

```python
for i in range(len(s)):
```

### Null terminator

In memory:

| Index | 0 | 1 | 2 | 3 |
|------|---|---|---|---|
| Value | 'c' | 'a' | 't' | '\0' |

The null terminator `'\0'` is the **only way to know when a string ends** in C.

So in this:
(~'s', ~'a', ~'l', ~'a', ~'-', ~'h', ~'a', ~'k', ~'k', ~'e', ~'r', ~'i', ~'-', ~'3', ~'2', ~'1', '\0')
It means: go until you get to that null terminator.

### Loop breakdown

- `int i = 0;` → Start at the first character  
- `s[i] != '\0';` → Stop when you hit the null terminator  
- `i++` → Move to the next character  

### Bitwise NOT

`s[i] = ~s[i];`

- `s` is a `char` array
- `~` flips bits: `1 → 0` and `0 → 1`
- That makes the character negative and int this case it makes it unreadable
