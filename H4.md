After opening it, I started the analysis.
I browsed the Symbol Tree and functions until I found something that looked like the main logic:

https://github.com/user-attachments/assets/e66a0614-e77b-4ca4-a3da-a99bac40113f

It looked like the main function, so I renamed FUN_001054d0 to main.
Understanding the functions

FUN_001053b7 looked like the comparison function.
The decompiled code looked like this:

/////////////////////////// c
int iVar1;
undefined1 local_28[32];

FUN_001053a7(0x10637f);
FUN_001053c7(0x106394, local_28);
iVar1 = FUN_001053b7(local_28, 0x106399);

if (iVar1 == 0) {
FUN_001053a7(0x1063a7);
} else {
FUN_001053a7(0x1063ed);
}
return 0;
///////////////////////////

Observations:

    FUN_001053a7 is clearly the print function (used for prompt + success + failure).

    FUN_001053c7 reads user input into local_28.

    FUN_001053b7 compares local_28 with the supposed password at 0x106399.

So the logic is:

    Print "What's the password?"

    Read input

    Compare input with password

    If equal → print flag

    Else → print "Sorry, no bonus."

I assumed 0x106399 was the password.
Converted it to decimal and tried it:

/////////////////////////// bash
./packd
What's the password?
1074073
Sorry, no bonus.
///////////////////////////

Still wrong.

    Packd reverse engineering
        Did you remember to unpack the packing?
    Training wheels as an adult?
        The only purpose of the tasks is to learn this thing.
        At work, you'll have to solve tasks yourself.
        Basics are learned with simple programs. These skills are applied to more complex programs over time.
        If all ideas and approaches are exhausted, then a model solution (or AI's direct answer) is better than nothing. It's always worth trying the task through even with instructions, so you'll know for the next one.
        Don't delegate learning to AI.
        Current AIs can solve easy tasks. But that's not very useful at work. The course tasks are easy because we're just learning. Skills must later be applied at a level that current AIs can't handle.
    Return value from a command in Bash
        'echo Tero; echo $?' prints "Tero\n0", where 0 is the return value.
        Zero means everything went well. Other numbers are errors.
