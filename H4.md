The check is basically:

``` c
if (iVar1 == 0)
```

- `iVar1 == 0` → password is correct  
- Anything else → password is wrong

---

### How to Reverse the Check

We want the program to **accept all wrong passwords** and reject the correct one.  
So we just invert the condition:

``` c
if (iVar1 != 0)
```

---

### Patching the Binary

Find the jump instruction for the `if` in Ghidra.

Original:

``` asm
001011a3 75 11    JNZ   LAB_001011b6    ; Jump if Not Zero
```

- JNZ → jumps if the password is wrong

Change it to:

``` asm
001011a3 74 11    JZ    LAB_001011b6     ; Jump if Zero
```

Now:
- Correct password jumps to the failure message  
- Wrong passwords are accepted

---

Export the patched binary and run it to check.

``` bash
./passtr_fix
```

## Understanding the Loop
Original loop:

``` c
for (local_c = 0;
    "password1"[local_c] != '\0' && (*(char *)((long)local_c + *(long *)(param_2 + 8)) != '\0');
    local_c++)
```

After analysis multible hours I made this to make it easier to understand:
``` c
for (i = 0;
    password1[i] != '\0' && argv[1][i] != '\0';
    i++)
```

---

### How the Code Works

**For loop:**

- `i = 0` → start counting from the first character of the string.  
- `i` is the **position in the string**, starting at `0`.

**Condition:**
``` yaml
password1[i] != '\0' && argv[1][i] != '\0'
```
- `argv` → argument vector:  
  - `argv[0]` → `./program`  
  - `argv[1]` → first argument (e.g., `hello` in `./program hello`)  
  - `argv[2]` → second argument (e.g., `world` in `./program hello world`)  
- Continue the loop as long as **both strings haven’t ended**.  

- `'\0'` marks the **end of the string**.

**Character comparison:**
``` c
if (password1[i] - 1 != argv[1][i]) {
    // ...
}
```

- Compares the current character of the user input to the **password character minus 1**.  
- The key detail is the **minus 1**. It is minus 1 of the ASCII character.
So password1 becomes o`rrvnqc0
