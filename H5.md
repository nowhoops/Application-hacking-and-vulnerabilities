## Root Cause
The function is likely:

```  
void print_scrambled(char *message) {  
    register int i = 3;  
    do {  
        printf("%c", (*message) + i);  
    } while (*++message);  
    printf("\n");  
}  
```
**I checked it it was correct**

The crash occurs because:

- `bad_message = NULL`  
- it breaks the function and causes a **segmentation fault**.

---
There were no clear explenation on what a fixed code should do. I found two fixes that don't break the code. 

### Fix Option 1 — Make the NULL a String

```  
#include <stdio.h>

void print_scrambled(char *message)
{
  register int i = 3;
  do {
    printf("%c", (*message)+i);
  } while (*++message);
  printf("\n");
}

int main()
{
  char * bad_message = "NULL";
  char * good_message = "Hello, world.";

  print_scrambled(good_message);
  print_scrambled(bad_message);
}
```

Output:

```
Khoor/#zruog1
QXOO
```

---

### Fix Option 2 —  IF NULL then message

```  
#include <stdio.h>

void print_scrambled(char *message)
{
    if (message == NULL) {
        printf("ERROR: NULL message\n");
        return;
    }

    int i = 3;
    do {
        printf("%c", (*message) + i);
    } while (*++message);
    printf("\n");
}

int main()
{
  char * bad_message = NULL;
  char * good_message = "Hello, world.";

  print_scrambled(good_message);
  print_scrambled(bad_message);
}
```

Output:

```
Khoor/#zruog1
ERROR: NULL message
```

---

## SUMMARY
- The crash occurs because `print_scrambled()` does not work with a NULL pointer.  
- Two valid fixes:  
  - Replace NULL with a real string  
  - Add a NULL check inside the function
