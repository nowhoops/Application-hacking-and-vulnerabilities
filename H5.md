## ❗ Root Cause
The function is likely:

```  
void print_scrambled(char *message) {  
    register int i = 3;  
    do {  
        printf("%c", (*message) + i);  
    } while (*++message);  
    printf("\n");  
}  
```

The crash occurs because:

- `bad_message = NULL`  
- The function dereferences it: `(*message)`  

This causes a **segmentation fault**.

---

### Fix Option 1 — Replace NULL with a String

```  
#include <stdio.h>

void print_scrambled(char *message)
{
  register int i = 3;
  do {
    printf("%c", (*message)+i);
  } while (*++message);
  printf("\n");
}

int main()
{
  char * bad_message = "NULL";
  char * good_message = "Hello, world.";

  print_scrambled(good_message);
  print_scrambled(bad_message);
}
```

# 🎉 Summary
- The crash occurs because `print_scrambled()` dereferences a NULL pointer.  
- Two valid fixes:  
  - Replace NULL with a real string  
  - Add a NULL check inside the function  

Both are acceptable depending on the assignment’s intent.
