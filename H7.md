#### Key points from the sections:
- **Encipher = Encrypt**, **Decipher = Decrypt**  
- Cryptography is about keeping messages secure.  
- Key: **authentication**, **integrity**, **nonrepudiation**.  
- A **cryptographic algorithm (cipher)** is a mathematical function used for encryption and decryption.  
- A good algorithm also needs a good implementation. Otherwise it could be insecure even if the math is fine.  
- Two main types of key-based algorithms: **symmetric** and **public key**.  
- **Cryptanalysis** means breaking encryption without the key.

#### Basic attack types:
- Ciphertext-only attack  
- Known-plaintext attack  
- Chosen-plaintext attack  
- Adaptive chosen-plaintext attack

### Final working script
``` Python
import string

userInput = "1b37373331363f78151b7f2b783431333d78397828372d363c78373e783a393b3736"

frequency = {
    'E': 12.02, 'T': 9.10, 'A': 8.12, 'O': 7.68, 'I': 7.31, 'N': 6.95,
    'S': 6.28, 'R': 6.02, 'H': 5.92, 'D': 4.32, 'L': 3.98, 'U': 2.88,
    'C': 2.71, 'M': 2.61, 'F': 2.30, 'Y': 2.11, 'W': 2.09, 'G': 2.03,
    'P': 1.82, 'B': 1.49, 'V': 1.11, 'K': 0.69, 'X': 0.17, 'Q': 0.11,
    'J': 0.10, 'Z': 0.07, ' ': 13.0
}

common_chars = string.ascii_letters + " .,!?';"

def score_text(text):
    score = 0
    for c in text.upper():
        if c in frequency:
            score += frequency[c]
        elif c in ".,!?;'\"":
            score += 1
        else:
            score -= 5
    return score

cipher_bytes = bytes.fromhex(userInput)

highest_score = float('-inf')
best_xor_key = None
best_decrypted_message = ""

for possible_key in range(256):
    candidate_bytes = bytes([byte ^ possible_key for byte in cipher_bytes])
    try:
        candidate_plaintext = candidate_bytes.decode('ascii')
        candidate_score = score_text(candidate_plaintext)
        if candidate_score > highest_score:
            highest_score = candidate_score
            best_xor_key = possible_key
            best_decrypted_message = candidate_plaintext
    except:
        continue

print(f"Best key: {chr(best_xor_key)} ({best_xor_key})")
print("Decrypted message:")
print(best_decrypted_message)


```
